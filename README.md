- **Subfield:** Radiative forcing, clouds, and climate sensitivity
- **Open:** Reconstruct seasonal and geographical preindustrial cloud-active aerosol populations, including natural sulfur, sea spray, dust, and organics. Determine how modern measurements constrain this counterfactual despite nonlinear cloud susceptibility.
